# Security

This repository contains an AI-agent skill and static reference files. It should
not contain credentials, private URLs, private customer data, or proprietary font
assets.

## Reporting

Please open a private security advisory or contact the maintainer if you find:

- A secret or credential.
- Private business or customer information.
- Unsafe install instructions.
- Guidance that would encourage bypassing accessibility, privacy, or browser
  security controls.

## Local Checks

Run:

```bash
./scripts/validate.sh
```
