# Contributing

Contributions are welcome when they keep the skill practical, accurate, and
portable across coding agents.

## Guidelines

- Keep `SKILL.md` concise; move detailed guidance to `references/`.
- Prefer original explanations over copied source text.
- Cite public documentation or idea lineage when it improves trust.
- Add browser-support-sensitive CSS as progressive enhancement.
- Keep examples generic and free of private client or business data.
- Run `./scripts/validate.sh` before opening a pull request.

## Good Contributions

- Updated browser support notes.
- Better WCAG or readability checks.
- Clearer font-loading examples.
- Safer starter CSS defaults.
- Short, concrete examples from public or fictional contexts.
